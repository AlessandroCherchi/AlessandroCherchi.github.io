# ▦ GUIDA UTENTE: GEN-BARCODE
**Generatore di Codici a Barre Offline per la GDO**

Questa guida ti spiega come utilizzare lo strumento per la creazione e la stampa di codici a barre, ottimizzato per l'uso su PC aziendali senza necessità di installazione o connessione internet.

---

## 🚀 Come Iniziare
1. Copia il file `barcode-generator.html` sul tuo PC (es. sul Desktop).
2. Fai doppio clic sul file per aprirlo. 
   - **Nota:** Si consiglia l'uso di **Google Chrome** o **Microsoft Edge** per una resa perfetta dei codici e della stampa.

---

## ➕ Metodi di Inserimento

### 1. Inserimento Manuale (o da Excel)
È il metodo più veloce per pochi codici o per liste copiate da un foglio di calcolo:
- **Seleziona il formato:** Scegli tra EAN-13, Code 128, ecc.
- **Nome Prodotto (Opzionale):** Se stai inserendo un solo codice, puoi scriverne qui la descrizione.
- **Codici:** Incolla qui la tua lista. Puoi incollare direttamente una colonna di **Excel**. Lo strumento riconoscerà automaticamente ogni riga come un codice diverso.
- **Pressione Invio:** Clicca su "Genera Barcode" per visualizzare le etichette.

### 2. Importazione da File (CSV / XML / TXT)
Se hai un file esportato dal gestionale o un archivio:
- Clicca nell'area tratteggiata o trascina il file all'interno.
- Se è un **CSV**, apparirà un pannello per "abbinare le colonne". Scegli quale colonna contiene il *Nome* e quale il *Codice*.
- Clicca su "Importa Righe".

---

## 🖨️ Stampa dei Codici

### Stampa Singola
- Clicca sull'immagine di un codice a barre per ingrandirlo.
- Clicca sul pulsante **"🖨 Stampa Questo"**. Si aprirà la finestra di stampa con solo quel codice ottimizzato per l'etichetta.

### Stampa Massiva (Tutto)
- Una volta generati tutti i codici necessari, clicca sul pulsante **"🖨 Stampa Tutto"** nella barra in alto.
- Lo strumento impaginerà automaticamente i codici in una griglia ordinata pronta per la tua stampante.

---

## 💡 Consigli Utili
- **Sicurezza:** Il tool è sicuro al 100%. Non invia dati all'esterno e non richiede permessi di amministratore.
- **Check Digit:** Per i formati EAN/UPC, lo strumento calcola o corregge automaticamente l'ultima cifra (di controllo) se inserisci solo le prime cifre del codice.
- **Pulizia:** Usa il tasto **"🗑 Svuota"** per cancellare la lista attuale e iniziare un nuovo lavoro.
